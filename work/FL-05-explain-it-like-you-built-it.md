# Explain It Like You Built It

## What I Chose
**The 4-Page Single-Action Portfolio Navigation Architecture (`portfolio_structure.txt`)**

## How It Works
Imagine building a house with four distinct rooms: a front porch (Home), a showcase gallery (Projects), a personal biography room (About), and a desk with a phone (Contact).

In my portfolio implementation, every room is designed so that no matter which door a visitor enters through, all paths gently guide them toward the desk phone to start a conversation:

1. **Home Page**: Acts as the front door. It leads with a Hero section, highlights SentinelOps as the lead project, displays a skills grid, and gives two clear buttons: *"View My Work"* (which opens the Projects gallery) and *"Contact Me"* (which jumps straight to the Contact desk).
2. **Projects Page**: Breaks down four core technical case studies—SentinelOps, GitVerse, VisionForge, and the FlyRank Internship. Each project case study follows an identical 5-part storyline: Problem, Work, Key Decisions, Measured Outcome, and Technical Details. At the bottom of every project breakdown, a dedicated button reads *"Contact Me About Opportunities"*.
3. **About Page**: Covers education, experience, technical interests, and project philosophy, ending with a photo and a *"Contact Me"* button.
4. **Contact Page**: Provides direct email, LinkedIn, GitHub links, and a simple contact form.

By linking every call-to-action button back to a single primary goal—contacting me for internship, research, or AI/ML opportunities—the visitor never gets stuck at a dead end or lost in deep navigation submenus.

## What I Learned
Before looking closely at this architecture, I assumed building a portfolio was just putting text and code links onto random web pages. I didn't realize that navigation is actually a structured funnel.

I learned that keeping an identical narrative layout across all four project breakdowns (Problem → Work → Decisions → Outcome → Tech Details) makes it much easier for recruiters to scan technical work quickly without relearning a new format on every page. I also learned the power of a single primary action: instead of overwhelming a visitor with competing requests, every section consistently leads them toward one clear next step.

## In My Own Words
When I first started organizing my work, I thought a portfolio was just a digital archive where you drop everything you've ever built. But looking at how my four pages connect, I realize it's really about guiding a visitor's attention. By keeping the structure predictable across all four project breakdowns and routing every button back to the contact section, the portfolio feels deliberate, clean, and easy to navigate.
